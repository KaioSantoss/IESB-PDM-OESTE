# MeuDiarioAcademico

Aplicativo desenvolvido em React Native com Expo para cadastro de disciplinas do semestre.

## Como criar o projeto

```bash
npx create-expo-app@latest MeuDiarioAcademico --template blank
```

Para iniciar:

```bash
npx expo start
```

## Funcionalidades

* Cadastro de disciplinas.
* Lista de disciplinas.
* Layout utilizando Flexbox.
* Uso de `StyleSheet`.
* Uso de `labels.js` para organizar os textos.

## Tecnologias

* React Native
* Expo
* JavaScript
